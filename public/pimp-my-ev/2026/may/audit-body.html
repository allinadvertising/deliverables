Proposed Solutions

Fix Shopify URL consolidation and parameter crawling first

1
Emit canonical tags in <head> for all indexable templates using Shopify's canonical_url value in theme.liquid.
2
Update product cards, recommendation blocks, collection grids, and app snippets so all internal links point to clean product URLs only.
3
Strip pr_prod_strat, pr_rec_id, pr_rec_pid, pr_ref_pid, pr_seq, _pos, _sid, _ss, aff, and internal utm_* from internal navigation links.
4
After links and canonicals are corrected, add targeted robots.txt.liquid disallow rules for non-content query patterns.

Normalize sitemap and orphan handling

1
Keep only canonical products, collections, pages, and blog posts in Shopify XML sitemaps : exclude parameterized URLs.
2
For orphan 200/indexable products, ensure active status, Online Store publication, collection assignment, and crawlable internal links.
3
For orphan 301/404 URLs, update internal link sources and maintain redirects only when a true successor exists.

Differentiate product and collection content

1
Create metafields for fitment, model years, materials, finishes, install notes, compatibility, package contents, warranty, and product FAQs.
2
Refactor templates to surface unique intro, fitment, specs, and install notes above repeated trust/shipping/recommendation modules.
3
Consolidate near-identical products and use Shopify variants where appropriate instead of separate pages.

Bulk repair SEO titles and meta descriptions

1
Export resources and update resource.seo.title and resource.seo.description via Admin, Matrixify, or API.
2
Apply concise title formulas that lead with product intent plus one differentiator (model, material, or year range).
3
Rewrite descriptions to 120:155 characters with a product-specific differentiator : avoid copying long body text.

Repair heading hierarchy in the Shopify theme

1
Move Recently Viewed and global modules below the H1 or render labels as paragraphs/divs.
2
Enforce exactly one H1 per template, mapping to product.title or collection.title as appropriate.
3
Demote repeated labels (e.g., IMPORTANT NOTE ABOUT THIS PRODUCT) to non-heading elements and guard against empty headings in Liquid.

Fix structured data parsing at the source template

1
Remove the empty application/ld+json script from the product template or app embed.
2
Render Product, ProductGroup, Offer, BreadcrumbList, Organization, and WebPage JSON-LD only when required variables are populated and escaped.
3
Validate representative templates in Google's Rich Results Test and Schema Markup Validator post-fix.
Current State
  • Internal links output parameterized product URLs that search engines can crawl and index.
  • Empty JSON-LD block triggers schema parse errors on product pages.
  • H1 is preceded by global modules, with repeated H2 labels across many pages.
  • Overlength and duplicate metadata limit snippet quality and CTR.
Recommended State
  • All internal navigation resolves to clean canonical product URLs, with canonicals reinforced in <head> and parameters disallowed for crawling.
  • Structured data validates cleanly with only populated JSON-LD blocks, restoring rich result eligibility.
  • Heading hierarchy is consistent : a single H1 first, utility sections demoted, and fewer duplicate headings.
  • Concise, differentiated titles and descriptions improve relevance and click-through rates.
Key Insight: Most duplication originates from navigational components : not editorial content. By cleaning internal link generation and reinforcing canonicals at the theme level, Pimp My EV can eliminate the majority of duplicate and near-duplicate issues without large-scale content rewrites.

Glossary: Technical Terms, Simplified

Canonical URL
The preferred version of a page that signals to search engines which URL should be indexed when duplicates exist.
Query Parameters
Key-value pairs appended to URLs (e.g., pr_prod_strat, _sid) often used for recommendations or tracking. They can create duplicate URLs if crawlable.
Orphan URL
A page that is not linked from any crawlable page on the site, making it hard for search engines to discover and recrawl.
Near-Duplicate Content
Pages with highly similar text and structure that dilute relevance and make it harder for one page to rank.
Heading Hierarchy (H1:H6)
The structured outline of a page. The H1 should be first and unique, followed by logical subheadings.
Meta Description
A short summary of a page shown in search results. While not a ranking factor, it strongly influences click-through rate.
JSON-LD (Structured Data)
A machine-readable data format that helps search engines understand page entities (e.g., Product, Offer) to enable rich results.

Frequently Asked Questions

What should we fix first to unlock results fastest?

We recommend prioritizing P0 items: remove parameterized internal links and reinforce canonical tags, then eliminate the empty JSON-LD block causing parse errors. These changes reduce index bloat and restore eligibility for rich results, improving visibility and CTR.

How long until we see impact after the URL consolidation?

Within 2:6 weeks as Google recrawls and reprocesses canonical signals. Sites with frequent product updates may see improvements sooner as important templates are revisited.

Which team owns what in this plan?

Client Dev updates theme templates, navigation, and structured data. AIA provides technical specifications, QA checklists, and validates fixes with crawls and schema testing. Metadata rewrites and content differentiation can be led by AIA with Client review.

Do we need to delete any pages?

We recommend consolidating parameter-driven duplicates and migrating true variants into Shopify variants. Retain canonical products and collections, keep redirects only where a legitimate successor exists, and remove indexable access to non-content parameter URLs.
