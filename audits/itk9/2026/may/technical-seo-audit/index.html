Heading Structure Critical

P0

Duplicate H1s, Multiple H1s, Non-Sequential Headings Across 91+ URLs

Root cause: The Webflow Collection template and reusable section headings are outputting block-level layout labels as semantic heading tags across dozens of location and content pages.
91 URLs with duplicate H1s
89 URLs with multiple H1s
48 URLs with non-sequential H1 structure
204 URLs with duplicate H2s
What This Means: BOARD & TRAIN PROGRAMS appears as the H1 on 48 location pages. 0% appears as a second H1 on the same 48 pages (the financing module uses an H1 tag for the APR value). FOLLOW THE PACK appears 101 times as an H2 because a reusable section block outputs a heading tag. Search engines cannot determine what any individual page is about when headings are duplicated across the entire site.

Proposed Solutions

1. Fix Webflow Heading Templates and Reusable Sections

1
Update the /board-and-train/ Collection template so each location page has one unique H1 such as Board and Train in {City}, instead of the static BOARD & TRAIN PROGRAMS repeated across all locations.
2
Demote the financing 0% text from H1 to non-heading text. If the financing module needs a heading, use a single section-level H2 (Pay Over Time With Affirm) and keep the APR value as plain text.
3
Change repeated layout labels such as FOLLOW THE PACK, About Our PROGRAMS, and program-card labels from H2 tags to non-heading elements unless they introduce a real content section.
4
Enforce a sequential page outline: one H1, primary sections as H2s, subsections and cards as H3s only when they sit under a relevant H2.

2. Normalize Webflow SEO Fields

1
Create dedicated CMS fields for SEO Title and Meta Description on Blog Posts, Board & Train Locations, service variant collections, and program collections.
2
Bind Collection page SEO settings to those fields instead of using full article excerpts, date-prefixed excerpts, or static fallback copy.
3
Bulk rewrite the 203 overlength descriptions to unique 120–155 character summaries. Start with the 126 /dog-training-tips/ URLs — the largest affected set.
4
Shorten the 54 overlength titles. For long blog titles, write a shorter SEO title rather than reusing the full H1. Remove unnecessary phrasing before the brand suffix.
5
Give legal, confirmation, and thank-you pages unique metadata only if they should remain indexable. If they are conversion or utility pages, exclude them from the sitemap and apply noindex.

3. Resolve Sitemap Orphaning

1
Audit every orphan URL and assign one of three outcomes: (1) keep and internally link it from a relevant hub, category page, blog index, or service page; (2) remove from the XML sitemap and apply noindex if it should not rank; (3) unpublish or 301 only when a true replacement exists.
2
Prioritize orphaned /dog-training-tips/ URLs with informational intent by linking them from the blog hub, related article modules, and relevant service pages.

4. Collapse Redirect Chains

1
Update all internal links, sitemap entries, and Webflow redirects so they point directly to the final canonical https://www.itraink9.ca/{path} URL without trailing slash.
2
In Webflow hosting and redirect settings, use a single-hop rule for non-www and trailing-slash variants wherever possible. After publishing, re-crawl the 62 flagged URLs and confirm each old URL reaches the final URL in one 301 hop.

Before & After: Heading Structure Fix

The highest-impact single change: patching the /board-and-train/ Webflow Collection template to output semantic, unique headings per location page.

Current: Single Template, Repeated Headings

Template outputs identical heading structure across all 48 location pages:

<h1>BOARD & TRAIN PROGRAMS</h1>
<h1>0%</h1> ← Financing APR
<h2>FOLLOW THE PACK</h2>
<h2>About Our PROGRAMS</h2>

Result: 48 pages all look identical to search engines. Google cannot distinguish Milton from Oakville.

Recommended: Semantic, Unique Headings

Each location page gets a unique, logical heading outline:

<h1>Board & Train in Milton</h1>
<h2>Our Training Programs</h2>
<h2>Pay Over Time With Affirm</h2>
<span>0% APR</span> ← Plain text

Result: Search engines see 48 unique pages, each targeting a different city. Duplicate H1s: zero. Duplicate H2s: fixed at template level.

Glossary: Technical Terms, Simplified

H1 / Heading Tags
The main headline search engines use to understand what a page is about. Every page should have exactly one unique H1. Multiple H1s or duplicate H1s across pages confuse search engines about which page should rank for what.
Orphan URL
A page on your site with no links pointing to it from any other page. It exists in the sitemap and Google's index, but users and link equity cannot reach it through normal navigation.
Crawl Budget
The number of pages Google scans on your site each day. Wasting it on duplicate URLs, redirect chains, or orphan pages means your important new content takes longer to appear in search results.
301 Redirect Chain
When a URL redirects to another URL, which then redirects again. Each hop consumes crawl budget and leaks a portion of the link equity. A single-hop redirect preserves full value.
Meta Description
The 1–2 sentence preview under your page title in Google results. It does not directly affect ranking, but a compelling, unique description earns more clicks. Google may rewrite descriptions over 155–160 characters.
Near-Duplicate Content
Pages that are so textually similar that search engines consider them interchangeable. When 48 location pages have identical content, only one is likely to rank — the others compete with it.
Canonical URL
The "official" version of a page you want Google to index. For iTK9, the canonical format is https://www.itraink9.ca/{path} without trailing slash.
CMS Collection Template
In Webflow, a reusable page layout that generates multiple pages from a single design. Fixing the template fixes every page that uses it — which is why patching the Board & Train template is the highest-leverage action in this audit.

Frequently Asked Questions

Q: Which fix should we do first?
Patch the /board-and-train/ Webflow Collection template. It resolves H1 duplicates, H2 duplicates, non-sequential headings, and near-duplicate content across 48+ pages in a single template change. Everything else builds from there.

Q: How fast will we see results?
Once fixes are published, Google needs to re-crawl the affected pages. Template fixes (headings, metadata) should reflect within 2–3 weeks. Redirect chain fixes are visible on the next crawl. Full impact across all issue categories: 4–6 weeks.

Q: What should our internal dev team handle vs All In Advertising?
Template changes and redirect configuration are Webflow admin tasks — typically handled by whoever manages the Webflow instance. AIA handles metadata rewrites, orphan URL triage, near-duplicate content strategy, and the re-crawl validation.

Q: Do we need to remove pages from the site?
Not necessarily. The recommendation is to triage each orphan and near-duplicate URL individually. High-value informational pages (blog tips) should be internally linked. Low-value utility pages (thank-you, confirmation) should be removed from the sitemap and noindexed. Only pages with zero distinct intent and no redirect target should be unpublished.
